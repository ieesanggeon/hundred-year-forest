# 백년의 숲: 깨어난 기사

100년의 잠에서 깨어난 기사가 공주를 구하기 위해 잃어버린 힘을 되찾는 Three.js 기반 3D 액션 RPG 프로토타입입니다.

## 실행 방법

온라인 배포는 `npm ci` 후 `npm run build`로 생성되는 `web-dist` 폴더를 사용합니다. Vercel에서는 저장소를 가져오면 `vercel.json`의 설정으로 자동 빌드합니다. 게임 실행에 서버 기능이나 비밀 환경변수는 필요하지 않습니다. 촬영 영상·임시 도구·의존성 폴더는 Git 업로드와 웹 배포에서 제외합니다.

1. `run_game.bat`을 더블 클릭합니다.
2. 서버가 준비되면 자동으로 열린 브라우저에서 게임을 시작합니다.
3. 자동으로 열리지 않으면 실행 창에 표시된 주소에 접속합니다. 기본 주소는 `http://127.0.0.1:8000`이며, 다른 프로그램이 그 포트를 사용하면 빈 포트로 바뀝니다.

별도의 게임 패키지 설치는 필요하지 않습니다. 배치파일은 Node.js를 우선 사용하고, 없으면 실제 Python을 찾아 로컬 웹 서버를 실행합니다. 같은 게임이 이미 켜져 있으면 기존 서버를 재사용합니다. 실패하면 오류 안내를 표시하고 창을 유지합니다. [Windows 실행기 설명과 검증](docs/windows-launcher.md)

권장 실행 방식은 `run_game.bat`입니다. 브라우저용 코드가 하나의 파일로 묶여 있으므로 `index.html`을 직접 열어도 시작할 수 있습니다.

## 조작법

| 조작 | 기능 |
| --- | --- |
| `W A S D` | 이동 |
| 마우스 왼쪽 클릭 | 목도로 공격 |
| 마우스 오른쪽 유지 | 방패 획득 후 정면 방어, 최대 3초 |
| `F` | 목도 줍기, 출구 조사 |
| `K` | 스킬 창 열기/닫기 |
| `E` | 테스트 콘솔 열기/닫기 |
| `C` | 1인칭·3인칭 시점 전환 |
| `Shift` + 이동 | 달리기 |
| `Space` | 점프 |
| `Esc` | 게임 일시정지·재개 |
| `Enter` | 대화 진행, 사막 100레벨 달성 후 출정 안내 열기 |
| 마우스 이동 | 상하좌우 시점 회전 |

## 현재 게임 흐름

1. 시작 화면에서 `눈을 뜬다`를 선택합니다.
   - 시작 배경은 평원 → 설원 → 사막 순서로 30초마다 바뀌는 실시간 Three.js 파노라마입니다. 설원에는 빙벽과 물을 마시는 매머드, 사막에는 피라미드와 오아시스·야자수·유적, 물을 마시는 낙타가 있습니다. [시작 파노라마 설명](docs/start-panorama.md)
2. 의문의 목소리에게 100년 동안 잠들어 있었다는 사실과 공주를 구해야 한다는 목표를 전달받습니다.
3. 평화로운 초원을 탐색하여 빛나는 낡은 목도를 줍습니다.
4. 초급 몬스터인 슬라임과 고블린을 처치하여 경험치를 얻습니다.
5. 요구 경험치를 채우면 레벨이 1 상승하고, 남은 경험치가 다음 레벨에 반영됩니다. 다음 요구 경험치는 이전보다 25% 증가합니다.
6. 모든 지역에서 레벨업마다 스킬 포인트를 1~4개 중 같은 확률로 무작위 지급합니다. 한 번에 여러 레벨이 올라도 레벨마다 따로 추첨합니다. 스탯 선택창에서 연속 클릭으로 포인트를 배분하고, `다음에 정하기`를 눌러 남겨둘 수 있습니다.
7. 보존한 스킬 포인트는 `K`를 눌러 나중에 직접 투자할 수 있습니다.
8. `E` 콘솔에서 캐릭터·검·방어력·경험치 획득 레벨을 조정하거나 다섯 스테이지로 이동할 수 있습니다. 성 본관 입구로 바로 가는 테스트 버튼도 있습니다.
9. 초원 25레벨에 오염된 숲, 오염된 숲 50레벨에 설원, 설원 75레벨에 메사 사막으로 가는 포탈이 열립니다. 메사에서는 100레벨까지 성장합니다.
10. 사막에서 100레벨을 달성하면 공주 구출 출정 안내가 중앙에 나타나고 게임이 잠시 멈춥니다. 체력과 무기 준비 안내를 확인하고 `더 준비하기` 또는 `Esc`로 닫을 수 있습니다. 마지막 레벨업의 남은 스킬 포인트는 이어지는 스탯 창에서 투자할 수 있습니다.
11. 출정 안내를 닫은 뒤 사막에서 `Enter`로 다시 열 수 있습니다. `성으로 향하기` 또는 팝업의 `Enter`로 검은 성의 다리 위에 도착합니다. 정상 본관에서는 황금·하양·핑크의 반인반수 보스 `백금의 폭군 아우렐리온`이 대사와 포효·화면 정지·이름 소개 후 전투를 시작합니다. 대사는 Enter로 넘길 수 있습니다.
12. 검은 성에서는 금빛 안내를 따라 올라가며 저격총을 든 오염된 수비병과 싸웁니다. 빨간 레이저가 고정되면 이동하거나 돌벽 뒤로 피하세요. 발사 시 제공한 총성이 재생됩니다. 경로는 약 2.73km이며 달리기 검사에서 본관까지 약 3분 54초가 걸렸습니다. 관문은 부활 지점이 되고, 보스를 쓰러뜨리면 공주의 봉인이 풀립니다. [검은 성 설명](docs/castle.md)

13. 보스를 처치한 뒤 공주에게 가까이 가면 마지막 대화가 자동으로 열립니다. 한 번에 한 문장씩 나오며 Enter로 다음 대사를 넘깁니다. 마지막 감사 인사에서 Enter를 누르면 홈 화면으로 돌아가고, 다시 시작하면 1레벨부터 새 게임을 진행합니다.

## 성장 규칙

- 검 강화: 투자할 때마다 검 레벨이 1 오르고 공격력이 12% 증가합니다. 초원은 검 50레벨, 오염된 숲과 설원은 100레벨, 메사 사막은 125레벨까지 강화할 수 있습니다.
- 경험치 획득량: 투자할 때마다 보너스 증가량도 +15% → +30% → +45% → +60%로 커집니다. 총 획득 배율은 1.15배 → 1.45배 → 1.90배 → 2.50배입니다. 스탯창에서 현재 배율과 다음 보너스를 확인할 수 있습니다.
- 방어력: 투자할 때마다 받는 피해가 8% 감소하며, 최대 감소율은 72%입니다.
- 최대 체력: 첫 포인트는 +10, 두 번째는 +20, 세 번째는 +30으로 투자할수록 증가량이 커집니다. 최대 체력이 늘어난 만큼 현재 체력도 회복합니다.
- 일반·희귀 몬스터와 수비병은 소환 순간의 검을 기준으로, 완충 일반 공격 최대 피해량의 3~5배 사이에서 무작위 정수 체력을 얻습니다. 최종 보스는 본관 진입 시 현재 검의 최대 일반 피해량의 20~25배로 체력을 확정합니다. 전투가 시작된 개체의 최대 체력은 그대로 유지합니다.
- 슬라임은 공격력 9와 기본 경험치 24, 고블린은 공격력 14와 기본 경험치 38을 갖습니다.
- 사망해도 레벨과 스킬은 유지되며 중앙 제단에서 다시 시작합니다.
- 검 강화 버튼은 현재 지역에서 허용한 최대 검 레벨에 도달하면 비활성화됩니다.
- 검을 강화할 때마다 기본 공격력이 12% 증가하고 이름과 3D 외형이 즉시 변경됩니다.

## 화면 및 시스템 구성

- Three.js의 원근 카메라, 실시간 조명, 그림자와 안개를 사용한 3D 월드입니다.
- 첫 시작 화면은 별도의 Three.js 실시간 파노라마 씬으로 렌더링됩니다.
- 계곡물과 폭포가 지속적으로 흐르고 물안개가 움직이며, 말이 고개를 숙여 물을 마십니다.
- 계곡 주변의 입체 나무와 수백 개의 풀이 바람에 흔들리고 파노라마 카메라가 천천히 좌우로 이동합니다.
- 초원은 입체적인 야생화와 나무로 표현했습니다.
- 외곽은 세 겹의 빽빽한 나무와 큰 바위 군락으로 둘러싸여 있으며, 보이지 않는 충돌 경계까지 적용되어 현재 지역을 벗어날 수 없습니다.
- 게임은 기본적으로 1인칭에서 시작하며 `C`를 누르면 1인칭과 3인칭이 전환됩니다. 1인칭 공격은 카메라가 바라보는 방향을 기준으로 판정합니다.
- 오프닝 대화가 끝나면 마우스가 게임 화면에 고정되어 버튼을 누르지 않고도 수평 360도와 상하 방향을 자유롭게 둘러볼 수 있습니다. `Esc`로 마우스를 풀고 게임 화면을 다시 클릭하면 재활성화됩니다.
- 브라우저가 첫 번째 `Esc` 입력을 마우스 잠금 해제에 사용하더라도 즉시 일시정지 화면이 열립니다.
- 슬라임과 고블린이 플레이어를 감지하면 눈과 몸을 플레이어 쪽으로 돌린 뒤 추적합니다.
- 슬라임은 공중으로 떠오르지 않고 바닥에 넓게 퍼진 밑부분과 아래로 처지는 돌기를 가진 형태로 움직입니다.
- 슬라임이 생성될 때 1% 확률로 햄버거 슬라임이 대신 등장합니다. 햄버거 슬라임의 공격력은 90이며, 체력은 다른 몬스터와 같은 소환 규칙으로 정합니다.
- 햄버거 슬라임은 빵, 패티, 치즈, 양상추와 소스 점액이 겹쳐진 희귀 외형이며 처치 시 기본 경험치 240을 줍니다.
- 일회성 스킬 `생명 감지`를 습득하면 모든 몬스터 머리 위에 현재 체력 비율을 나타내는 체력바가 표시됩니다.
- `생명 감지`를 한 번 습득하면 완료된 항목은 스킬창에서 사라져 다른 성장 스킬에 집중할 수 있습니다.
- 화면 왼쪽 위 미니맵에는 플레이어의 위치와 방향, 슬라임, 고블린과 햄버거 슬라임의 실시간 위치가 표시됩니다.
- 미니맵 색상은 플레이어 하늘색, 슬라임 연두색, 고블린 주황색, 햄버거 슬라임 금색입니다.
- 몬스터 체력바는 밝은 테두리와 고채도 색상을 사용하며, 체력이 줄어들면 밝은 초록색에서 노란색, 빨간색으로 변합니다.
- 몬스터는 시간에 따라 자동 생성되지 않습니다. 한 마리를 처치하면 약 1.25초 뒤 플레이어에게서 최소 24 거리 이상 떨어진 곳에 대체 몬스터가 한 마리 생성됩니다.
- 1레벨 필요 경험치를 100에서 160으로 높이고 다음 레벨 요구량 증가율을 22%에서 25%로 높여 전체 성장 시간을 늘렸습니다.
- 1인칭 화면 중앙에는 공격 방향을 확인할 수 있는 십자 조준선이 표시됩니다.
- 1인칭에서 공격하면 목도가 화면 아래에서 올라오며 전방을 가르는 동작이 표시됩니다.
- `K`로 스탯창을 연 상태에서 스탯창 밖의 게임 화면을 클릭하면 창이 닫히고 마우스 시점 조작으로 돌아갑니다.
- 북쪽에는 25레벨 조건을 보여주는 봉인된 숲길이 있습니다.
- HUD에는 현재 목표, 레벨, 체력, 경험치, 공격력, 피해 감소율, 남은 스킬 포인트가 표시됩니다.
- 공격은 플레이어가 현재 바라보는 방향의 전방 180도 반원, 거리 4.2 안에 있는 모든 적에게 적용됩니다.
- 좌클릭으로 검을 공격하고, 성 수비병을 처음 처치해 방패를 얻으면 우클릭 유지로 정면을 최대 3초 방어합니다. 시간 종료 후에는 우클릭을 놓았다 다시 눌러야 합니다. 해금 시 자세한 사용법 팝업이 나타납니다.
- 최종 보스는 기존 두 기술에 삼연참·두 차례 빛기둥·유성 발사를 더한 다섯 패턴을 사용합니다. [보스 패턴·방패 설명과 개별 테스트](docs/boss-patterns-and-shield.md)
- 공격 피격, 피해 숫자와 경험치 획득 표시로 전투 반응을 표현했습니다.
- 진행 상황은 현재 플레이 중에만 유지됩니다. 새로고침하면 시작 화면과 1레벨부터 다시 시작합니다.

## 파일 구성

- `index.html`: 게임 화면, HUD, 대화, 스킬 및 사망 UI
- `styles.css`: 전체 화면 구성과 판타지 UI 디자인
- `src/game.js`: Three.js 3D 월드, 추적 카메라, 180도 전투, 몬스터 AI, 성장
- `package.json`: Three.js 로컬 라이브러리 의존성
- `dist/game.bundle.js`: Three.js와 게임 코드를 하나로 묶은 실제 브라우저 실행 파일
- `run_game.bat`: 로컬 서버 실행 및 브라우저 열기
- `server.js`: Node.js가 있을 때 사용하는 무설치 정적 파일 서버
- `CHANGELOG.md`: 작업 단위별 변경 기록
- `forest_rpg.py`: 기존 방향 확인용 3D 테스트 코드로 보존

## 개발 후 실행 파일 갱신

`src/game.js`를 수정한 뒤에는 프로젝트 폴더에서 `npm run build`를 실행하면 `dist/game.bundle.js`가 갱신됩니다. 일반 플레이에는 이 과정이 필요하지 않습니다.
