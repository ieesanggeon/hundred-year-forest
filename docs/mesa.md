# 4스테이지 · 붉은 메사 협곡

## 해금과 이동

- 3스테이지 설원에서는 50레벨부터 75레벨까지 성장한다.
- 설원에서 75레벨이 되면 화면 중앙 위에 해금 안내가 나타나고 카메라가 북쪽 돌문을 비춘다. 포탈이 나타날 때 개방 효과음이 한 번 재생된다.
- 포탈 안으로 걸어 들어가면 메사 사막의 시작 지점으로 이동한다. 사막의 캐릭터 상한은 100레벨이며 검 강화 상한은 125레벨이다.
- `E` 콘솔에 4스테이지 이동 버튼을 추가했다. 지역을 왕복해도 캐릭터 레벨과 장비는 유지된다.

## 100레벨 출정 안내

- 일반 경험치 또는 E 콘솔로 100레벨에 도달하면 중앙에 “공주를 구하러 갈 시간입니다” 팝업을 띄운다.
- 최종 보스전 출정 분위기에 맞춰 검정·보라·회색 배경, 은회색 테두리, 보라색 왕관과 출발 버튼을 사용한다.
- “드디어 공주를 구하러 갈 수 있습니다. Enter를 누르면 검은 성으로 향합니다.”와 “충분한 체력과 강력한 무기를 준비한 후 출발하세요.”를 표시한다.
- 팝업이 열리면 이동·전투를 멈추고 마우스를 해제한다. `더 준비하기` 또는 Esc로 닫을 수 있으며, 마지막 레벨업의 스탯 선택은 닫은 뒤 이어진다.
- 이후 사막에서 Enter를 누르면 다시 열 수 있다. 성으로 향하기 버튼 또는 Enter 확인으로 검은 성의 입구 다리 위에 이동한다. [검은 성 설명](castle.md)

## 지형

- 붉은 갈색, 주황, 황토, 연한 사암색이 번갈아 이어지는 아홉 층의 지형을 배치했다.
- 외곽 지형은 안쪽의 높이 0m에서 바깥쪽의 약 16.5m까지 기울어져 올라간다. 각 층이 바깥쪽으로 2.5~3.4m가량 물러나며 경사를 이룬다.
- 색층의 경계에는 완만한 굴곡을 주고 바깥에는 여러 색층을 가진 테이블형 바위를 세웠다.
- 내부에는 모래 언덕과 선인장, 바람에 흩날리는 먼지를 추가했다. 플레이 공간은 경사면의 안쪽 경계에 제한된다.

## 몬스터

| 이름 | 외형과 동작 | 공격력 | 경험치 |
| --- | --- | ---: | ---: |
| 코브라 | 똬리, 올라간 몸, 펼친 후드, 송곳니와 갈라진 혀 | 55 | 500,000 |
| 사막전갈 | 여덟 다리, 두 집게, 마디진 꼬리와 독침 | 68 | 700,000 |

소환 시 현재 검의 완충 일반 공격 최대 피해량의 3~5배 범위에서 개체별 체력을 정한다. 머리 위 이름·체력과 미니맵에 연결했고, 몬스터를 처치하면 플레이어에게서 먼 곳에 새 몬스터가 나타난다. 생성 시 무작위 방향을 바라보고 배회 방향으로 회전하며 어그로가 끌리면 플레이어를 추적한다.

## 검 101~125레벨

새 검 25종은 각자 다른 칼날 좌표와 가드, 태양석 수를 가진다. 휘어진 시미터, 송곳니, 집게, 쌍날, 넓은 대검과 왕관형 검을 포함한다. 금빛 장식과 주황빛 태양석을 사용하고 마지막 125레벨 검에는 왕관과 추가 창날을 달았다.

모든 이름은 [검 이름 전체 목록](sword-names.md)에 레벨순으로 기록했다. 1인칭과 3인칭에 같은 모델을 적용하며 HUD와 스킬 창, 테스트 콘솔에서 125레벨 상한을 사용한다.

## 배경음악

- 사용자가 제공한 `Footsteps_on_Crimson_Sand.mp3`를 `assets/crimson-sand.mp3`로 복사해 사막 지역에 적용했다.
- 사막 입장 시 음량 35%로 반복 재생하고, 다른 지역으로 이동하면 해당 지역 음악으로 전환한다.
- 사망·일시정지 때 멈추며 부활·재개하면 멈춘 위치부터 이어서 재생한다.

## 검증

`npm run build` 후 `node tests/stage-three.cjs`로 다섯 지역의 진행과 성장 상한, 무기 형상, 몬스터 생성과 방향, 왕복 이동, 음악 및 사망·부활을 검사한다. 메사와 새 검 비교 화면도 별도 브라우저에서 렌더링해 확인했다.
