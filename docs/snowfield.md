# 3스테이지 · 만년설 분지

## 진입과 성장

- 오염된 숲에서 캐릭터 50레벨에 도달하면 북쪽 돌문을 비추는 해금 연출이 재생된다.
- 포탈이 나타나는 순간 기존 포탈 개방 효과음이 한 번 들린다. 포탈 안으로 걸어가면 설원의 시작 지점으로 이동한다.
- 설원은 캐릭터 75레벨까지 성장하며 레벨당 스킬 포인트를 1~4개 중 무작위로 지급한다. 검 강화 상한은 100레벨이다.
- 75레벨을 달성하면 북쪽 돌문에 메사 사막으로 가는 포탈이 열린다. 사막에 진입하면 다시 경험치를 얻어 100레벨까지 성장할 수 있다.
- `E` 콘솔의 3스테이지 이동 버튼으로 즉시 테스트할 수 있다. 지역을 옮겨도 캐릭터와 장비의 성장 상태는 유지된다.

## 지형

- 플레이 공간의 네 가장자리에서 바깥쪽으로 갈수록 높아지는 얼음벽을 배치했다.
- 얼음벽은 다섯 개의 연속 경사층이며, 층 경계에 얼음판과 흰 눈 덮개가 겹쳐 있다. 높이 약 15m까지 경사지게 올라가며 수직 벽처럼 보이지 않도록 설계했다.
- 바닥에는 눈더미와 금이 간 얼음 호수가 있고 눈이 내린다. 이동 한계는 얼음벽 안쪽에 있어 외곽으로 나갈 수 없다.
- 배경음악은 `Crossing the Silent Ridge`가 35% 음량으로 반복 재생된다. 사망·일시정지 때 멈추고 부활·재개하면 이어서 재생된다.

## 몬스터

| 이름 | 특징 | 공격력 | 기본 경험치 |
| --- | --- | ---: | ---: |
| 북극곰 | 흰 털, 검은 코, 네 발 보행 | 40 | 8,500 |
| 설원 미라 | 붕대, 푸른 눈, 어깨의 얼음 결정 | 34 | 7,000 |
| 해동된 메머드 | 거대한 몸, 긴 코와 상아, 몸에 남은 얼음 | 75 | 35,000 |

첫 배치와 재생성 때마다 1% 확률로 해동된 메머드가 등장한다. 일반 몬스터는 북극곰과 설원 미라다. 소환 시 현재 검의 완충 일반 공격 최대 피해량의 3~5배 범위에서 개체별 체력을 정한다. 생명 감지를 습득하면 이름, 현재 체력, 최대 체력, 체력바가 표시된다.

## 50~75레벨 검

## 검사

`npm run build` 후 `node tests/stage-three.cjs`를 실행하면 기존 지역의 포탈, 50레벨 해금, 설원 이동과 왕복, 희귀 몬스터, 무기 26개의 고유 형상, 재생성, 사망·부활을 검사한다.
