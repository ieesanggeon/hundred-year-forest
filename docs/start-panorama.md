# 시작 화면 파노라마

## 장면과 전환

- 처음 0~30초에는 평원 계곡, 30~60초에는 설원 계곡, 60~90초에는 사막 오아시스를 보여 준다. 90초부터 평원으로 돌아와 같은 순서로 반복한다.
- 프레임 수 대신 실제 경과 시간을 기준으로 배경을 선택한다. 전환 전후 약 0.65초 동안 배경만 어두워졌다 밝아지고 제목과 시작 버튼은 계속 표시된다.
- 어느 배경에서든 눈을 뜬다 버튼으로 기존 오프닝과 1스테이지를 시작한다. 파노라마는 전투 지역과 별개이며 시작한 뒤에는 갱신하지 않는다.
- 시작 카드의 폭과 높이를 줄여 물가의 동물을 가리지 않도록 했으며, 설원은 푸른 회색, 사막은 따뜻한 갈색 색상을 사용한다. 세로 화면은 카메라 위치와 시야각을 조정한다.

## 설원 계곡

- 참고 이미지의 구도를 바탕으로 밝은 겨울 하늘, 울퉁불퉁한 설산 능선과 오른쪽의 푸른 빙벽을 실제 Three.js 메시로 구성했다.
- 넓은 계곡에 흐르는 물결과 반사광을 표현하고, 양쪽 물가에는 눈 덮인 바위와 침엽수, 붉은 겨울 열매를 배치했다.
- 왼쪽 물가의 매머드는 털과 네 다리, 굽은 상아 두 개와 긴 코를 갖는다. 약 8초 주기로 머리와 코가 움직이며 물가에 동심원 파문이 퍼진다.
- 눈발과 구름, 나무 흔들림과 느린 카메라 이동으로 배경이 계속 움직인다.
- 반복되는 식생과 바위·빙벽 기둥은 인스턴싱으로 묶고, 눈발과 물결은 셰이더로 갱신한다. 매번 장면을 다시 만들지 않고 세 장면을 재사용한다.

## 사막 오아시스

- 참고 이미지에 맞춰 두 개의 피라미드와 모래 언덕을 뒤쪽에, 푸른 오아시스와 야자수를 전경에 배치했다. 피라미드의 석재는 층별로 크기가 줄어들며 색과 틈이 다르다.
- 야자수의 굽은 줄기와 개별 잎사귀, 코코넛을 만들고, 잎과 물가 풀은 바람에 흔들린다. 물가에는 작은 바위와 수련 잎을 배치했다.
- 왼쪽 물가의 낙타는 혹, 긴 목과 네 다리, 붉은 안장과 짐을 갖는다. 약 8초마다 목을 움직이며 물을 마시고 입가의 파문이 퍼진다.
- 오른쪽 둑 위에는 기둥과 상인방, 부러진 돌무더기의 고대 유적을 놓았다.
- 물결·반사광과 모래 결, 낮게 흘러가는 모래 입자와 느린 구름 이동을 애니메이션으로 표현했다. 이 배경은 전투 지역과 별개다.

## 관련 파일

- `src/snow-panorama.js`: 설원 시작 배경과 환경 애니메이션.
- `src/desert-panorama.js`: 사막 오아시스 시작 배경과 환경 애니메이션.
- `src/game.js`: 기존 평원 파노라마, 30초 전환과 화면 크기 조절, 게임 시작 연결.
- `index.html`, `styles.css`: 배경 전환용 가림막. 참고 이미지의 설명표나 글자는 게임 배경에 넣지 않는다.
